# 01 — 环境搭建与项目初始化

## 前置条件

- Windows 10/11 PC
- Git 已安装
- TAPTAP MAKER 编辑器已安装（星火编辑器）
- 网络可访问 GitHub

---

## 步骤 1：克隆源项目

```bash
cd C:\Projects
git clone https://github.com/FilthyFrost/lordhand.git
cd lordhand
```

源游戏代码位于 `GAME/` 目录，关键数据文件：
- `GAME/data/chunks/chunk_X_Z.json` — 地图碰撞/渲染数据
- `GAME/data/baked/manifest.json` — 区域索引
- `GAME/data/static/manifest.json` — 静态碰撞索引
- `GAME/scripts/` — 所有游戏逻辑（JavaScript）

## 步骤 3：入口文件 main.lua

```lua
-- main.lua — LORDHAND MAKER 移植入口
require "LuaScripts/Utilities/Sample"
local UI = require("urhox-libs/UI")

-- 模块引用
local FPSCamera = require("scripts/camera/FPSCamera")
local PlayerPhysics = require("scripts/player/PlayerPhysics")
local PlayerMovement = require("scripts/player/PlayerMovement")
local HandModel = require("scripts/player/HandModel")
local WorldLoader = require("scripts/world/WorldLoader")
local ChunkRenderer = require("scripts/world/ChunkRenderer")
local SpatialHash = require("scripts/world/SpatialHash")
local WeaponSystem = require("scripts/combat/WeaponSystem")
local ProjectileSystem = require("scripts/combat/ProjectileSystem")
local DemonRegistry = require("scripts/enemies/DemonRegistry")
local Juice = require("scripts/vfx/Juice")
local BattleHUD = require("scripts/ui/BattleHUD")
local Config = require("scripts/config")

---@type Scene
local scene_ = nil
local gameState = "menu"  -- "menu" | "playing" | "paused"

function Start()
    SampleStart()
    SampleInitMouseMode(MM_RELATIVE)

    CreateScene()
    WorldLoader.Load(scene_, function()
        -- 地图加载完毕后初始化游戏系统
        SpatialHash.Build(WorldLoader.GetColliders())
        PlayerPhysics.Init(scene_, Config.PLAYER_START_POS)
        FPSCamera.Init(scene_, PlayerPhysics.GetNode())
        HandModel.Init(scene_, FPSCamera.GetCameraNode())
        WeaponSystem.Init(scene_, FPSCamera, HandModel, ProjectileSystem)
        ProjectileSystem.Init(scene_, SpatialHash, DemonRegistry)
        DemonRegistry.Init(scene_)
        Juice.Init(FPSCamera)
        BattleHUD.Init()
        gameState = "playing"
    end)

    SubscribeToEvents()
end

function Stop()
    UI.Shutdown()
end

function CreateScene()
    scene_ = Scene:new()
    scene_:CreateComponent("Octree")
    -- 注意：不创建 PhysicsWorld（我们用自实现 AABB 碰撞）
    scene_:CreateComponent("DebugRenderer")

    -- 光照：使用 DarkNight 预设匹配原游戏暗色调
    local lightGroupFile = cache:GetResource("XMLFile", "LightGroup/DarkNight.xml")
    local lightGroup = scene_:CreateChild("LightGroup")
    lightGroup:LoadXML(lightGroupFile:GetRoot())

    -- 调整雾效匹配原游戏
    local zone = lightGroup:GetComponent("Zone", true)
    if zone then
        zone.fogStart = Config.FOG_START
        zone.fogEnd = Config.FOG_END
        zone.fogColor = Config.FOG_COLOR
    end
end

function SubscribeToEvents()
    SubscribeToEvent("Update", "HandleUpdate")
    SubscribeToEvent("PostUpdate", "HandlePostUpdate")
    UnsubscribeFromEvent("SceneUpdate")
end

function HandleUpdate(eventType, eventData)
    if gameState ~= "playing" then return end
    local dt = eventData["TimeStep"]:GetFloat()

    -- 输入
    FPSCamera.UpdateInput(dt)

    -- 玩家移动
    PlayerMovement.Update(dt, FPSCamera.GetYaw())
    PlayerPhysics.Update(dt)

    -- 战斗
    WeaponSystem.Update(dt)
    ProjectileSystem.Update(dt)

    -- 敌人
    DemonRegistry.Update(dt, PlayerPhysics.GetPosition())

    -- VFX
    Juice.Update(dt)

    -- 手模型
    HandModel.Update(dt, WeaponSystem.GetState())
end

function HandlePostUpdate(eventType, eventData)
    if gameState ~= "playing" then return end
    local dt = eventData["TimeStep"]:GetFloat()

    -- 相机最终位置（在所有物理之后）
    FPSCamera.PostUpdate(dt, PlayerPhysics.GetPosition())

    -- HUD 更新
    BattleHUD.Update(PlayerPhysics.GetHealth(), WeaponSystem.GetNeedleCount(),
                     PlayerPhysics.GetPosition().y)
end
```

## 步骤 6：数据文件准备

在正式开始编码前，需要先执行数据转换（详见 [10-数据转换工具链](10-数据转换工具链.md)）：

1. 将 `GAME/data/chunks/chunk_X_Z.json` 转换为 Lua table 文件
2. 将轨道曲线数据提取为 `rails.lua`
3. 用工具生成所有 .ogg 音效文件

转换后数据放入 `assets/Data/` 目录。

---

## 关键注意事项

1. **不创建 PhysicsWorld** — 原游戏使用自实现 AABB 碰撞，不依赖 Bullet 物理引擎。移植保持一致，避免引入不必要的复杂性。
2. **不使用 KinematicCharacterController** — 同上，移动系统纯 Lua 实现。
3. **光照选择 DarkNight** — 原游戏视觉风格极暗，使用最暗的 LightGroup 预设。
4. **坐标系差异** — Three.js 右手系 vs MAKER 左手系，Z 轴方向相反。在数据转换阶段处理（negate Z）。
5. **require 路径** — MAKER 中 require 使用 "/" 分隔，不带 .lua 后缀。
